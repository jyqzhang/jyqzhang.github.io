# Project workflow

For website edits in this project, check the changes, then commit and push them
and verify the live deployment at https://jyqzhang.github.io. Do this by default
unless the user explicitly asks for a preview only.

## Private collection draft

The books / films / music section in `playground/on-my-desk/` is local-only.
Do not publish its files or restore its public Playground entry unless the user
explicitly requests publication of this section. Keep this directory ignored.
